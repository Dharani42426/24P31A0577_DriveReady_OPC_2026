
# Day 3 - Agent or Not?

## Campus Canteen Assistant

### 1. Check food item price
Example: Find the price of Idli.

Category: Plain Python Code

Reason: We can get the price directly from a Python dictionary.

### 2. Answer student questions
Example: Explain the available food items in simple English or Telugu.

Category: One LLM Call

Reason: An LLM can understand the question and generate a helpful response.

### 3. Manage canteen orders
Example: Check menu details, verify availability with the canteen system, calculate the bill and prepare an order summary.

Category: AI Agent

Reason: This task requires multiple steps and tools to complete the work.

## Conclusion

Simple calculations can use Python code.
Understanding natural-language questions can use one LLM call.
Tasks requiring multiple steps and tools can use an AI agent.
