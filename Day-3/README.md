
# Day 3 - Campus Canteen Assistant

## Topics Learned

- Difference between a chatbot and an AI agent
- Four parts of an AI agent:
  - Brain
  - Instructions
  - Tools
  - Memory
- Agent working process
- Traditional AI, Generative AI and Agentic AI
- Introduction to LangChain
- Prompt templates and chains
- Testing an AI assistant

## Project

The Campus Canteen Assistant helps students get information about the sample canteen menu, prices and timings.

## Practical Tasks

1. Create a system prompt for the Campus Canteen Assistant.
2. Create 10 customer questions in tests.csv.
3. Test the assistant and calculate the pass rate.
4. Improve the prompt and compare results.
5. Change temperature to 1.0 and observe the responses.
6. Identify three canteen tasks that need plain code, one LLM call or an AI agent.

## Goal

Build a basic AI assistant using LangChain and understand how agents work.
