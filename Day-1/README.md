# Day 1 - Campus Canteen Assistant

## Project Introduction
Campus Canteen Assistant is an AI chatbot that helps students get information about food items, prices and canteen timings.

## What I Learned
- Introduction to AI and LLMs
- System prompts
- Connecting an LLM using Groq
- Asking questions and generating responses

## Sample Menu
- Idli - Rs. 30
- Veg Sandwich - Rs. 40
- Lemon Juice - Rs. 25
- Coffee - Rs. 20

Note: These are sample details for this project.

## Assistant Rules
- Answer politely.
- Do not invent prices or menu items.
- If information is unknown, say that it needs to be checked.
